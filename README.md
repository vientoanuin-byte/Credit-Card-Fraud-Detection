## 📊 数据集

**数据集来源**：Kaggle公开的[Credit Card Fraud Detection Dataset](https://www.kaggle.com/mlg-ulb/creditcardfraud)

**数据集特征**：

- **样本规模**：284,807条信用卡交易记录
- **特征维度**：31维（Time, Amount + 28个PCA降维特征 + 目标变量Class）
- **类别分布**：极度不平衡
  - 正常交易：284,315条（99.83%）
  - 欺诈交易：492条（0.17%）
- **数据质量**：无缺失值，Amount存在右偏分布与极端值

## 📈 主要结果

### 模型性能对比

| 模型              | 精确率 (欺诈类) | 召回率 (欺诈类) | F1-Score (欺诈类) | AUC-ROC          |
| ----------------- | --------------- | --------------- | ----------------- | ---------------- |
| 逻辑回归          | 0.12            | 0.91            | 0.21              | 0.9756           |
| 随机森林          | 0.83            | 0.83            | 0.83              | 0.9692           |
| **XGBoost** | **0.66**  | **0.89**  | **0.76**    | **0.9818** |

### 关键发现

1. **XGBoost表现最佳**：在AUC-ROC指标上达到0.9818，展现了最强的整体排序能力
2. **SMOTE效果显著**：消融实验显示，使用SMOTE使XGBoost的AUC从0.93895提升至0.98178
3. **特征重要性**：PCA特征V14、V17、V12等对欺诈检测贡献最大
4. **可解释性洞察**：SHAP分析揭示了关键特征对预测的正负向影响模式

## 🔍 误差分析与案例研究

项目特别关注模型的失败案例，深入分析“模型何时出错”：

### 典型案例

| 样本编号 | 真实类别 | 预测概率   | 错误类型 | 分析要点                         |
| -------- | -------- | ---------- | -------- | -------------------------------- |
| 14233    | 正常 (0) | 0.99998724 | 假阳性   | 模型以99.9987%置信度误判正常交易 |
| 2779     | 正常 (0) | 0.999736   | 假阳性   | 模型以99.9736%置信度误判正常交易 |
| 20994    | 欺诈 (1) | 0.000214   | 假阴性   | 模型以极低概率漏检欺诈交易       |

### 误差归因

1. **假阳性原因**：正常交易的极端特征组合意外匹配欺诈模式
2. **假阴性原因**：欺诈交易的特征表现偏离模型学习的主流模式
3. **改进方向**：特征工程优化、业务规则后处理、持续监控迭代
